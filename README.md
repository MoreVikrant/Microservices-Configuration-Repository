# Microservices-Configuration-Repository
Centralized configuration repository for a Spring Boot microservices architecture using Spring Cloud Config Server and Spring Cloud Gateway.

# 📌 Overview

This repository contains externalized configuration files for the microservices in the application.

The configuration is managed centrally through Spring Cloud Config Server, allowing individual microservices to retrieve their configuration from a single Git repository.

The project demonstrates:


Eureka Service Registry Centralized Configuration
Manual API Gateway routing Configuration
